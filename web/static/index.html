Configuración de Inteligencia Artificial

Conecta tu proveedor de IA ingresando la URL de su API, tu clave de acceso y seleccionando el modelo deseado (soporte completo para la Familia Luna 6 y OpenAI).

Ingresa la URL del proveedor web de tu API (ej: para Familia Luna 6 o proxies). Déjalo vacío si usas el endpoint oficial de OpenAI.

Tu clave API y configuración se almacenan en tu propio archivo local config/settings.json y nunca se comparten con terceros.
